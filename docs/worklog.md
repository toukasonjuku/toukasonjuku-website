# 作業ログ

コミット（`c`/`cp`）のたびに、**このファイルの先頭**に新しいエントリを追記する。worklog追記とコミットは同じコミットに含めること（追記漏れのままpushしない）。

## テンプレート

```
### YYYY-MM-DD 作業概要（関連タスク: docs/tasks.md の該当項目）
- 内容: 何をしたか
- コミット: `<git short SHA>`
- 確認: 動作確認・検証した内容（自動テストが無いプロジェクトのため、ローカルサーバーでの目視確認が基本）
- 次にやること: あれば
```
